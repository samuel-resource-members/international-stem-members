```text
4.   A Bauman string is a string of letters that satisﬁes the following two conditions.

          • Each letter in the string is A, B, C, D, or E.

          • No two adjacent letters in the string are the same.

      For example, AECD and BDCEC are Bauman strings of length 4 and length 5,
       respectively, and ABBC and DAEEE are not Bauman strings.

          (a) How many Bauman strings of length 5 are there in which the ﬁrst letter and the
               last letter are both A?
         (b) Determine the number of Bauman strings of length 6 that contain more than
           one B.
          (c) Determine the number of Bauman strings of length 10 in which the ﬁrst letter
                 is C and the last letter is D.
```
