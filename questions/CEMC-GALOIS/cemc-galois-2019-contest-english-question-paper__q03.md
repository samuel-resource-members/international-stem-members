```text
3.   If n is a positive integer, the notation n! (read “n factorial”) is used to represent the
    product of the integers from 1 to n. That is, n! = n(n −1)(n −2) · · · (3)(2)(1).  For
    example, 5! = 5(4)(3)(2)(1) or 5! = 120.

          (a) What is the largest positive integer m for which 2m is a divisor of 9! ?

         (b) What is the smallest value of n for which n! is divisible by 72?

          (c) Explain why there is no positive integer n for which n! is divisible by 77 but is not
              divisible by 78.

         (d) Show that there is exactly one positive integer n for which

                              n! = 2a · 3b · 5c · 7d · 112 · 132 · 17 · 19 · 23, and

                                    a + b + c + d = 45

              for some positive integers a, b, c, d.
```
