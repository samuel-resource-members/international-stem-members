## Text (OCR)

```text
Problem 5.  Let n be a positive integer. We have n boxes where each box contains a non-negative
number of pebbles. In each move we are allowed to take two pebbles from a box we choose, throw
away one of the pebbles and put the other pebble in another box we choose. An initial conﬁguration
of pebbles is called solvable if it is possible to reach a conﬁguration with no empty box, in a ﬁnite
(possibly zero) number of moves. Determine all initial conﬁgurations of pebbles which are not solvable,
but become solvable when an additional pebble is added to a box, no matter which box is chosen.
```
