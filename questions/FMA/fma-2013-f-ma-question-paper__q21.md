21. The experiment is repeated with a new pendulum with a rod of length 4L, using the same angle θ0, and the period
    of motion is found to be T. Which of the following statements is correct?

         (B) T > 2T0 with T ≈2T0 if θ0 ≪1.
         (C) T < 2T0 with T ≈2T0 if θ0 ≪1.
         (D) T > 2T0 for some values of θ0 and T < 2T0 for other values of θ0.
         (E) T0 and T are undeﬁned because the motion is not periodic unless θ0 ≪1.
