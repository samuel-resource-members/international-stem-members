32.  Solid calcium carbonate is in equilibrium as described
    below:
      Ca2+(aq) + 2HCO3 – (aq) ⇌ CaCO3(s) + CO2(g) +H2O(l)
      If CO2(g) is added to this system in a rigid container,
    which changes will take place?
         I. Additional CaCO3(s) will precipitate.
        II. The pH will increase.

    (A)  I only                  (B)  II only

    (C) Both I and II           (D)  Neither I nor II
