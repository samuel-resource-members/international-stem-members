```text
10. The number of moles of a weak monoprotic acid is
    determined by titrating with standardized NaOH solution
     to a phenolphthalein endpoint. The procedure calls for
     the acid to be dissolved in 50 mL of distilled water. What
     error would be introduced by using 75 mL of distilled
    water instead?

    (A) The number of moles would increase significantly.

    (B) The number of moles would decrease significantly.

    (C) The number of moles would not be significantly
          affected.

    (D) The number of moles would be decreased by the
        change if the indicator concentration is low but
         increased if the indicator concentration is high.
```
