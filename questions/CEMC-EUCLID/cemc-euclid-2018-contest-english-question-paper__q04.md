4.        (a) The positive integers 34 and 80 have exactly two positive common divisors,
           namely 1 and 2. How many positive integers n with 1 ≤n ≤30 have the
            property that n and 80 have exactly two positive common divisors?

         (b) A function f is deﬁned so that
               • f(1) = 1,
               • if n is an even positive integer, then f(n) = f 2n1    , and
               • if n is an odd positive integer with n > 1, then f(n) = f(n −1) + 1.
            For example, f(34) = f(17) and f(17) = f(16) + 1.
           Determine the value of f(50).
