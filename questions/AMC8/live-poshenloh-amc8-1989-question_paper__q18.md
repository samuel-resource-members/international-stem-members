## Statement

A calculator has a reciprocal key that replaces the number currently displayed with its reciprocal. For example, if the display shows \(4\) and the key is pressed, the display becomes \(0.25.\) If \(32\) is currently displayed, what is the fewest number of times the reciprocal key must be pressed so that the display again reads \(32?\)
