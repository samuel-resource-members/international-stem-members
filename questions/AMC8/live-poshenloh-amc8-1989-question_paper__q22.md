## Statement

The letters \(A,\) \(J,\) \(H,\) \(S,\) \(M,\) \(E\) and the digits \(1,\) \(9,\) \(8,\) \(9\) are each cycled separately (shifted one place at a time) to build a numbered list. Starting from AJHSME \(1989,\) the list begins: line \(1\) is JHSMEA \(9891,\) line \(2\) is HSMEAJ \(8919,\) line \(3\) is SMEAJH \(9198,\) and so on. On what numbered line will AJHSME \(1989\) appear for the first time?
