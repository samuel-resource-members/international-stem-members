4.        (a) Suppose that c is a real number.  Solve the following system of equations for
          x and y in terms of c:

                                      3x + 4y = 10

                                      5x + 6y = c

         (b) Determine all integers d for which the system of equations

                                     x + 2y = 3

                                      4x + dy = 6

            has a solution (x, y), where x and y are integers.

          (c) Determine a positive integer k for which there are exactly 8 integers n for which
            the system of equations

                            (9n + 6)x −(3n + 2)y = 3n2 + 6n + (3k + 5)
                          (6n + 4)x + (3n2 + 2n)y = −n2 + (2k + 2)

            has a solution (x, y), where x and y are integers.
