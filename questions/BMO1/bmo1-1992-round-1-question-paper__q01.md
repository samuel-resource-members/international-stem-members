## Text (OCR)

```text
- (a) Observe that the square of 20 has the same number
of non-zero digits as the original number. Does there
exist a two-digit number, other than 10, 20 or 30, whose
square has the same number of non-zero digits as the
original number? If you think there is one, then find
it. If you claim that there is none, then you must prove
your claim.
(b) Does there exist a three-digit number other than 100,
200, 300 whose square has the same number of non-zero
digits as the original number?
```
