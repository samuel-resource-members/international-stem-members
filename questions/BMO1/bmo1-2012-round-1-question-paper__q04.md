```text
4.  Initially there are m balls in one bag, and n in the other, where m, n >
    0. Two diﬀerent operations are allowed:

   a) Remove an equal number of balls from each bag;
   b) Double the number of balls in one bag.
    Is it always possible to empty both bags after a ﬁnite sequence of
   operations?
   Operation b) is now replaced with
    b′) Triple the number of balls in one bag.

    Is it now always possible to empty both bags after a ﬁnite sequence of
   operations?
```
