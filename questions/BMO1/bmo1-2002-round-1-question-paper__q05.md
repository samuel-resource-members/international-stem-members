5. f  is a function from Z+ to Z+, where Z+ is the set of non-negative
    integers, which has the following properties:-
   a) f(n + 1) > f(n) for each n ∈Z+,
   b) f(n + f(m)) = f(n) + m + 1 for all m, n ∈Z+.
   Find all possible values of f(2001).
