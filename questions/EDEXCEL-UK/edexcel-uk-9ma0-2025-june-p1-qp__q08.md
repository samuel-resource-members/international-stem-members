```text
8. A student was asked to prove that the square of any number can be expressed in the form 5n or 5n ± 1 where n ∈ ℕ.
The start of the student’s proof is shown in the box below.
Let m = 5k
Consider m² = (5k)² = 25k² = 5 × 5k² = 5n where n = 5k² ✓
Let m = 5k + 1
Consider m² = (5k + 1)²
= 25k² + 10k + 1 = 5(5k² + 2k) + 1 = 5n + 1 where n = 5k² + 2k ✓
Let m = 5k + 2
Consider m² = (5k + 2)²
= 25k² + 10k + 4 = 5(5k² + 2k + 1) − 1 = 5n − 1 where n = 5k² + 2k + 1 ✓
(a) Identify and correct an algebraic error in the box above. (1)
(b) Show the calculations and statements that are required to complete the proof. (4)
```
