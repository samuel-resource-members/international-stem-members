```text
6   A student attempts to solve the equation

                                 cos x + sin x tan x = 2 sin x −1

       in the range 0 ≤x ≤2π.

     The student’s attempt is as follows:


           cos x + sin x tan x = 2 sin x −1



         So   cos x −sin x + sin x tan x −sin x = −1                             (I)



         So   (sin x −cos x)(tan x −1) = −1                                     (II)



         So   sin x −cos x = −1  or tan x −1 = −1                             (III)


         So   (sin x −cos x)2 = 1  or tan x = 0                            (IV)



         So  2 sin x cos x = 0  or tan x = 0                             (V)


         So  x = 0, π2, π, 3π2 , 2π                                         (VI)



     Which of the following best describes this attempt?


   A  It is completely correct

   B  It is incorrect, and the ﬁrst error occurs on line (I)

   C  It is incorrect, and the ﬁrst error occurs on line (II)

   D  It is incorrect, and the ﬁrst error occurs on line (III)

    E   It is incorrect, and the ﬁrst error is that extra solutions were introduced on
           line (IV)

    F   It is incorrect, and the ﬁrst error is that extra solutions were introduced on
           line (V)

   G  It is incorrect, and the ﬁrst error is not eliminating the values where tan x is
        undeﬁned on line (VI)
```
