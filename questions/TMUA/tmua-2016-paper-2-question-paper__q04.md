```text
4 Five sealed urns, labelled P, Q, R, S, and T, each contain the same (non-zero) number of
balls. The following statements are attached to the urns.
Urn P This urn contains one or four balls.
UrmnQ This urn contains two or four balls.
UmR This urn contains more than two balls and fewer than five balls.
UrnS This urn contains one or two balls.
Urn T This urn contains fewer than three balls.
Exactly one of the urns has a true statement attached to it.
Which urn is it?
A UrmP
B UrmnQ
C UrmR
D UrnS
E UrnT
```
