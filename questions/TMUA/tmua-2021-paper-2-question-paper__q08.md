8    Consider the following statement about the polynomial p(x), where a and b are real
     numbers with a < b :


         (∗)  There exists a number c with a < c < b such that p′(c) = 0.


     Which one of the following is true?

   A The condition p(a) = p(b) is necessary and suﬃcient for (∗)

   B  The condition p(a) = p(b) is necessary but not suﬃcient for (∗)

   C  The condition p(a) = p(b) is suﬃcient but not necessary for (∗)

   D The condition p(a) = p(b) is not necessary and not suﬃcient for (∗)
