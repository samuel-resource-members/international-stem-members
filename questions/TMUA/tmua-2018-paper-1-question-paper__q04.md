```text
4     Consider the simultaneous equations



                                      3x2 + 2xy = 4

                                    x + y = a


     where a is a real constant.

     Find the complete set of values of a for which the equations have two distinct real
       solutions for x.

   A  There are no values of a.

   B −2 < a < 2

   C −1 < a < 1

   D  a = 0

    E  a < −1  or a > 1

    F  a < −2  or a > 2

   G  All real values of a
```
