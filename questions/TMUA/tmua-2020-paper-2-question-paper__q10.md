10   The real numbers a, b, c and d satisfy both

                                   0 < a + b < c + d

     and
                                   0 < a + c < b + d


     Which of the following inequalities must be true?


             I   a < d

             II   b < c

            III  a + b + c + d > 0


   A  none of them

   B  I only

   C  II only

   D  III only

    F   I and III only

   G  II and III only

   H   I, II and III
