SPLICING
Sir Richard Roberts (1943-present) discovered the fundamental structure of genes using adenovirus genomes.
Under an electron microscope, Roberts identified adenoviral DNA and RNA strands. Eukaryotic mRNA was
later found to be missing parts (introns) of the genes, because the RNA sequence was rearranged by splicing.
RNA strand
DNA strand
True False
Each adenovirus RNA is transcribed from the same DNA strand for the whole RNA.
Adenovirus mRNA remains bound in a DNA-RNA hybrid duplex for a period of time.
Transcription requires helicase activity (separates the two DNA strands).
mRNA splicing of these Adenovirus genes uses a similar mechanism to typical Eukaryotic splicing.
