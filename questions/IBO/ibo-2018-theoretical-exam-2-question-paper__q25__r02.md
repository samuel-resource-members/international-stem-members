Shell Coiling
In snail, the direction of cleavage, and therefore the snail shell coiling, is controlled by a single gene, 
in which the right-coiling allele, D, is dominant to the left-coiling allele, d. Below table shows the 
results of a set of mating experiment. 
Indicate if each of the following statements is true or false:

If the egg cytoplasm of a recessive homozygous right-coiling mother is injected
into the eggs of the “dd” mother, the resulting embryos coil to the left.
