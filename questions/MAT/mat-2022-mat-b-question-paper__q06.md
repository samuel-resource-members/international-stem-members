## Text (OCR)

```text
F. The series

               1 + (1 + x −x2) + (1 + x −x2)2 + (1 + x −x2)3 + . . .

               1
converges to           for precisely which real values of x?
           x(x −1)

  (a)  If and only if −1 < x < 1,

 (b)  If and only if we have both x ̸= 0 and x ̸= 1,

  (c) If and only if either −1 < x < 0 or 1 < x < 2,

 (d)  If and only if either −2 < x < −1 or 0 < x < 1,

  (e) For all real x.
```
