```text
Question 26 Y
Linear polynomials are functions of the form a + bx with a and b real numbers.

Given two linear polynomials, we define an operation  · as follows. To calculate
f(x) · g(x), we multiply the polynomials as normal, but we ignore any x2 term.

For example, (1 −2x) · (3 −5x) = 3 −11x, because we are ignoring the 10x2 term.

  (i) (a) Find the coefficients of (a+bx) · (c+dx) in terms of a, b, c, d, and explain why
        f(x) · g(x) = g(x) · f(x) for all linear polynomials f(x) and g(x).

     (b) Find a linear polynomial f(x) such that f(x) · (1 + 2x) = (3 + 4x).
                                                            3 marks

  (ii) A strictly increasing linear function f(x) has the property that if y > x then f(y) >
     f(x).

   A student claims that if f(x) and g(x) are both strictly increasing linear functions,
     then so is f(x) · g(x).  Is the student correct?  If so, prove the student’s claim.
     Otherwise, find a counterexample.
                                                            2 marks

 (iii) Prove that
                        (f(x) · g(x)) · h(x) = f(x) · (g(x) · h(x))

      for all linear polynomials f(x) and g(x) and h(x).

     [For the rest of the question, we will assume this result and write f(x) · g(x) · h(x)
     to mean either expression above.]
                                                            2 marks

 (iv) Let N be a whole number with N > 1. Find

                 (1 + x) · (1 + 2x) · (1 + 3x) · (1 + 4x) · . . . · (1 + 2Nx).

                                                            3 marks

 (v) Given that f(x) and g(x) are linear polynomials and f(x) · g(x) = 0, describe all
      possibilities for the pair f(x) and g(x).                          2 marks

 (vi) Given that f(x) and g(x) and h(x) are linear polynomials and

                                f(x) · g(x) · h(x) = 0,

     prove that at least one of the following statements must be true;

        (I) f(x) · g(x) = 0,

       (II) g(x) · h(x) = 0,

      (III) f(x) · h(x) = 0.

     For each of the three statements, give examples of polynomials for which that
     statement is true and the other two statements are false.             3 marks
```
