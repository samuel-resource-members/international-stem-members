## Text (OCR)

```text
I. The number of positive solutions x to the equation

                                 log2 x = log2(x + a) + b,

where a and b are non-zero real numbers, is

  (a) zero if ab < 1, or one if ab > 1,

 (b) one if ab < 1, or two if ab > 1,

  (c) one if ab < 0, or zero if ab > 0,

 (d) zero if ab < 0, or one if ab > 0,

  (e) one if ab < 1, or zero if ab > 1.
```
