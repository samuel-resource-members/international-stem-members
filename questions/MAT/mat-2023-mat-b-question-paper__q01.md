## Text (OCR)

```text
A. The function p(x) = x3 is an example of a polynomial with the property that there
is a point on the graph y = p(x) with zero derivative which is neither a local maximum
nor a local minimum. Which one of the following polynomials has the same property?

  (a) y = x3 −3x2 + x

 (b) y = x3 −3x2 + 2x

  (c) y = x3 −3x2 + 3x

 (d) y = x3 −3x2 + 4x

  (e) y = x3 −3x2 + 5x
```
