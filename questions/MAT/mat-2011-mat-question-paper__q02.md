## Text (OCR)

```text
2. For ALL APPLICANTS.

Suppose that x satisﬁes the equation

                             x3 = 2x + 1.          (∗)

(i) Show that
                     x4 = x + 2x2    and    x5 = 2 + 4x + x2.

(ii) For every integer k ⩾0, we can uniquely write

                              xk = Ak + Bkx + Ckx2

where Ak, Bk, Ck are integers. So, in part (i), it was shown that

           A4 = 0, B4 = 1, C4 = 2    and    A5 = 2, B5 = 4, C5 = 1.

Show that
                Ak+1 = Ck,    Bk+1 = Ak + 2Ck,    Ck+1 = Bk.

(iii) Let
                        Dk = Ak + Ck −Bk.
Show that Dk+1 = −Dk and hence that

                        Ak + Ck = Bk + (−1)k .

(iv) Let Fk = Ak+1 + Ck+1. Show that

                             Fk + Fk+1 = Fk+2.
```
