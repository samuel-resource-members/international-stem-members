17. Suppose a is a real number such that the equation

                      a ⋅(sin x + sin(2x)) = sin(3x)


   has more than one solution in the interval (0, π). The set of all such a can be written in
   the form (p, q) ∪(q, r), where p,q, and r are real numbers with p < q < r. What is
   p + q + r?

     A   −4

    B   −1

    C   0

    D   1

     E   4
