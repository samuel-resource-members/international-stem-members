## Text (OCR)

```text
4. Given a positive integer n, let b(n) denote the number of positive
   integers whose binary representations occur as blocks of consecutive
   integers in the binary expansion of n.   For example b(13) = 6
   because 13 = 11012, which contains as consecutive blocks the binary
   representations of 13 = 11012, 6 = 1102, 5 = 1012, 3 = 112, 2 = 102
   and 1 = 12.
Show that if n ≤2500, then b(n) ≤39, and determine the values of n forwhich equality holds.
```
