## Text (OCR)

```text
4, Given a set of n people, it is desired to arrange a
series of bridge games such that every two of the n
people play as opponents in exactly one game.
Show that this can be done if and only if n is of the
form n = 8m+1, where m is a positive integer.
(There is no restriction on the number of times, if
any, two people play as partners. )
```
